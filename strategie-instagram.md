# Stratégie Instagram — CV Builder AI France 2026

## Ce qui rend Instagram différent des autres canaux

L'algorithme Instagram 2026 a un signal #1 pour distribuer le contenu à de nouvelles
personnes : les envois en DM. Pas les likes, pas les vues — les DM. Quand quelqu'un
envoie une vidéo à un ami, Instagram récompense massivement en portée.

Pour le niche CV/emploi, c'est parfait. Le réflexe naturel de quelqu'un qui voit
"Ton CV est peut-être rejeté automatiquement" c'est de l'envoyer à un ami qui cherche
du boulot. C'est du partage utilitaire — exactement ce qu'Instagram récompense.

---

## Les Formats qui Marchent

### Reels — Format Principal

**7-15 secondes (viral pur)**
- Hold rate maximal → l'algo propulse
- Format : Avant/Après — l'impact visuel suffit, pas besoin d'explication
- Objectif : DM sends + saves

**30-60 secondes (éducatif)**
- Assez de temps pour expliquer une erreur ATS et convaincre d'aller sur le site
- Objectif : saves + clics lien bio

Règle d'or : **hold rate >60% dans les 3 premières secondes = 5 à 10x plus de reach**.
En dessous, l'algo coupe la distribution.

---

### Carousels — Format Oublié mais Très Efficace

Spécifique à Instagram — ni TikTok ni Shorts ne l'ont vraiment.

**Exemple :** "10 erreurs qui font rejeter ton CV par les ATS" — une erreur par slide.
- Fort taux de sauvegarde (les gens gardent pour relire)
- Les saves sont le 2ème signal fort après les DM
- Dans le pipeline n8n : Claude génère le texte de chaque slide, Creatomate assemble
  automatiquement

**Structure type d'un carousel :**
```
Slide 1 : Hook — "10 erreurs qui font rejeter ton CV automatiquement"
Slide 2-11 : Une erreur par slide (titre + explication courte + icône)
Slide 12 : CTA — "Teste ton score ATS gratuitement — lien en bio"
```

---

### Stories — Pour les Abonnés Existants

Pas pour l'acquisition — pour la conversion.
Une fois la base d'abonnés construite, les Stories servent à :
- Rappeler le CTA ("lien en bio, teste ton CV")
- Poser des questions ("tu connais ton score ATS ?")
- Garder l'audience chaude entre les Reels

## Audience Instagram vs TikTok

| | TikTok | Instagram |
|---|---|---|
| Âge dominant | 18-28 ans | 25-40 ans |
| Profil | Étudiants, primo-entrants | Actifs en poste ou reconversion |
| Pouvoir d'achat | Faible | Plus élevé |
| Objectif canal | Volume + notoriété | Conversion Pro €19/mois |

L'audience Instagram est moins volumineuse mais **plus prête à payer**.
C'est là que viennent les premiers abonnés Pro, pas sur TikTok.

## Adaptation du Pipeline n8n pour Instagram

Même vidéo que TikTok pour le format Avant/Après, mais Claude génère une légende
différente selon le canal :

**TikTok :**
```
"Ton CV invisible pour les ATS 😱 → voilà comment le rendre visible
#CV #emploi #ATS #recrutement #jobsearch"
```

**Instagram :**
```
"74% des CV ne passent pas les filtres automatiques.
Le tien est peut-être dedans. Lien en bio pour vérifier."
```

Règles Instagram dans le prompt Claude :
- Ton plus sérieux, moins d'emojis
- 3 hashtags max (pas de liste à rallonge)
- CTA direct vers lien en bio
- Pas de questions rhétoriques — affirmations chiffrées

---

## Ce qui ne S'automatise Pas

Le profil fondateur. Les Stories "coulisses" de la construction du produit,
les posts personnels qui montrent les chiffres de croissance — ce contenu crée
la confiance et convertit les curieux en clients. Il ne peut pas venir d'un pipeline auto.

**Fréquence recommandée :** 2-3 posts perso par semaine depuis le compte fondateur,
en complément des Reels automatisés.
